# Orcs & Elves II

[Играть в браузере](https://pilotofasuka.github.io/orcs-elves-ii-remastered/brew/)

Возвращение в тёмные подземелья: исследуйте древние залы, находите сокровища, сражайтесь с чудовищами и раскройте историю волшебной палочки.

Игра для браузера с удобным управлением на компьютере и телефоне. Classic сохраняет оригинальную графику BREW. Remastered будет постепенно получать улучшенные текстуры и спрайты; переключение вида сохраняет ваше приключение.

Интерфейс на русском и английском. На телефоне доступны экранные кнопки.

WASD / стрелки — движение · Enter — действие · M — карта · I — рюкзак · F5 / F9 — сохранить / загрузить · F2 — переключить вид.

Сейчас новая версия находится в разработке: Classic уже доступен для игры, улучшенная графика Remastered появится позже.

[Play in your browser](https://pilotofasuka.github.io/orcs-elves-ii-remastered/brew/)

Return to dark dungeons, discover ancient halls and hidden treasures, battle monsters, and uncover the story of a mysterious wand.

Play on desktop or mobile with English and Russian interface options and touch controls. Classic preserves the original BREW graphics. Remastered visuals are being developed and will share the same adventure and saves.

WASD / arrow keys — move · Enter — action · M — map · I — inventory · F5 / F9 — save / load · F2 — switch view.
