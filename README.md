# Orcs & Elves II

Возвращение в тёмные подземелья: исследуйте древние залы, находите сокровища, сражайтесь с чудовищами и раскройте историю волшебной палочки.

Игра для браузера с удобным управлением на компьютере и телефоне. Classic сохраняет оригинальную графику BREW. Remastered будет постепенно получать улучшенные текстуры и спрайты; переключение вида сохраняет ваше приключение.

Сейчас новая версия находится в разработке.
