# Локализация интерфейса

Выбор перед запуском: Русский / English; последнее предпочтение сохраняется
в отдельном language.cfg. Игра не выполняет tick до выбора.

Исходный пользовательский JAR 4.9.9 содержит pt/cz/pl/ru/tr, без английского.
Английские тексты взяты из текстовых ресурсов 4.3.2; код/уровни/таблицы этой
версии не используются и её классы не исполняются.

Источник: https://www.myabandonware.com/game/orcs-elves-ii-vvv
SHA-256 английского JAR:
6e834662707770d5631763245c766faf416dc8ad4fd3401d6f24b0f74a6ca029

Локальная копия: research/languages/reference-432.jar (не в Git).

tools/import_english.py принимает ровно этот архив, проверяет все 12 групп,
1605 ID и совпадение %1…%6 для каждой строки. Числовые строки сохраняются
из пользовательского оригинала. tests/export_locale_catalog.gd декодирует
его русский character mapping из world fixture и создаёт en.json.

OEText — только представление. Меню/названия извлекаются по ID; сообщения и
подстановки сопоставляются с исходными шаблонами. Таймеры, страницы и все
игровые решения остаются в оригинале. Все snapshot сохраняют русский
исходный граф; выбранный язык применяется при чтении.

localization.gd проверяет оба выбора, английский HUD/вступление/сообщение и
неизменность checksum полного графа. Полного прохождения обоих языков ещё нет.
