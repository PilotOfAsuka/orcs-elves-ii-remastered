# GitHub и браузерная версия

[Играть](https://pilotofasuka.github.io/orcs-elves-ii-remastered/) · [Репозиторий](https://github.com/PilotOfAsuka/orcs-elves-ii-remastered)

Публикация устроена по образцу WolfMoon:

- `godot` — исходный Godot-проект и история разработки.
- `web-build` — проверенный экспорт Web: HTML, JavaScript, WebAssembly и пакет игры.
- GitHub Pages — публикация корня ветки `web-build`.

Экспорт использует Godot 4.7.2, WebGL 2 и один поток; специальные COOP/COEP
заголовки для запуска не требуются. Игра работает в подкаталоге репозитория.
Для обновления нужно импортировать ресурсы, выполнить экспорт Web, проверить
сборку и запустить `python3 tools/publish_github.py publish` после коммита
исходников. Скрипт использует существующую авторизацию Git, не сохраняет и не
печатает ключи доступа. `status` показывает состояние Pages.

В исходники не входят переданный JAR, декомпиляция, research, vendor, кэши,
локальные сборки и сохранения. На Pages отправляются только файлы экспорта.
Сохранения находятся в браузере; локальный адрес и сайт Pages имеют отдельные
хранилища. Проект Orcs & Elves II отделён от сохранений WolfMoon.

Это развивающийся порт. Текущее состояние и непроверенные сценарии описаны в
[PROGRESS.md](../PROGRESS.md) и [REMAINING_WORK.md](../REMAINING_WORK.md).
